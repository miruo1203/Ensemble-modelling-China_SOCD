This repository presents an advanced ensemble modeling approach for predicting soil bulk density (BD) across China.  The methodology integrates predictions from four machine learning models - Support Vector Machines (SVM), Cubist, Random Forest (RF), and Gradient Boosting Machine (GBM) - using the Granger-Ramanathan framework to achieve superior predictive accuracy.  The ensemble model combines the strengths of individual algorithms through weighted regression (y_EM = a × y_SVM + b × y_Cubist + c × y_RF + d × y_GBM + e), with coefficients optimized via least squares.  All models were developed using 5-fold cross-validation to prevent overfitting and ensure robustness, with data split at the profile level (75% training, 25% validation) to maintain spatial independence.  The implementation includes comprehensive evaluation metrics (R², Concordance, RMSE, RPD, RPIQ) through a standardized accuracy function and supports feature selection via Forward Random Forest Selection (FRFS) for RF modeling.  The code is organized into modular scripts for each model (SVM. kt, Cubist. kt, RF. kt, GBM.kt) and ensemble integration (Ensemble modelling.kt), requiring R packages (kernlab, caret, dplyr, Cubist, ranger) for execution.  This approach demonstrates state-of-the-art performance for soil BD prediction as validated in recent pedometric research (Chen et al., 2024).

For detailed implementation, see the individual model scripts and ensemble integration code.
